# STEPX 狂想计划 · 梦境相册 —— 剪辑工程（edit-v1）

横屏 1920×1080，30fps，全片 **4:27.2**。整条片子是一个网页播放器，画面在浏览器里实时画，不用渲染。混好的声音在 `网页版/mix.m4a`。

## 怎么看

1. 拉代码：`git checkout edit-v1 && git pull && git lfs pull`（素材都在 LFS 里，必须 pull 下来）
2. 打开：双击 `剪辑工程/预览.command`（Mac）或 `剪辑工程/预览.bat`（Windows）；
   也可以在仓库根目录跑 `python3 剪辑工程/网页版/serve.py`，浏览器会自己打开。用 **Chrome**。
3. 快捷键：空格播放/暂停，← → 前后 1 秒，`,` `.` 逐帧；下拉框可以直接跳到任意一句。

## 导出成片

```bash
pip3 install playwright          # 第一次
python3 剪辑工程/网页版/tools/export_mp4.py            # 整条 → 剪辑工程/成片输出/网页版成片.mp4
python3 剪辑工程/网页版/tools/export_mp4.py --small    # 另外压一个 < 30MB 的交付版
python3 剪辑工程/网页版/tools/export_mp4.py --from 100 --to 130   # 只导一段试看
```

用的是本机 Google Chrome（能解 H.264）。第一次导出会把原片转一份关键帧密的副本到 `网页版/_export/`（只在本地，不进 Git）。

## 声音

- 人声：出镜（4K 原片音轨）和非出镜（wav）两条录音按听感响度对齐，片段两端 25 毫秒淡入淡出。
- 配乐 6 段，全部来自曲库，已拷到 `剪辑工程/音乐/`。换曲一律交叉淡化，没有硬切。

| 时间 | 曲子 | 怎么对的点 |
|---|---|---|
| 0:00–0:32 | Mind Heist（Zack Hemsey，《盗梦空间》预告） | 第一句说完、切到峡谷那一刀是重拍；「回到主人身边」也落在重拍上；阿亮一开口，曲子正好落进它自己的静音缝里收住 |
| 0:33–1:51 | futuristic-view | 阿亮出镜下是轻铺垫，曲子「起来」那一下对准 STEPX Neo 大字 |
| 1:50–2:32 | Time（Hans Zimmer，《盗梦空间》）开头 | 安静钢琴垫梦境；弦乐进来那一下对准「梦境相册」大字 |
| 2:31–3:10 | smart-sparks | 轻快电子垫录屏 |
| 3:09–3:46 | Time 高潮段 | 讲梦时铺进来；曲子最大的一次重进对准相册成品亮相 |
| 3:45–4:29 | hopeful piano | 真机测试、早上醒来是安静钢琴；高潮对准「那些疯狂念头」，高潮结束的地方正好是片尾 |

  两首《盗梦空间》是有意选的：片子里的梦（往天上对折的城市）本身就是盗梦空间的意象。
- 电平三档（相对人声听感响度）：停顿或纯画面 −8 dB，口播下 −17 dB，真人出镜 −24 dB。安静段落另外做了音量走势，不会听不见。
- 音效 25 个，分四类：
  - 12 个段落切点的甩镜声。
  - 6 个大字的重击：20%、STEPX Neo、软硬模一体、人人都是AI创客、梦境相册、AmooStore。其中 STEPX Neo、人人都是AI创客、梦境相册三个前面还带一声上扬。
  - 「让我来拍板」「校验通过」两下盖章。
  - 两次对折转场。

  小徽章、小卡片都不配声。
- 母带：−14 LUFS，限幅 −1.5 dB。
- 想换曲：改 `代码/mix.py` 顶部的 `MUSIC` 表（每行：曲子、曲内对齐秒、成片对齐时刻、起止），然后跑 `python3 剪辑工程/代码/mix.py`，几十秒就好。加 `check` 会出一张声画对位图到 `网页版/_tmp/sync.png`。
  - 备选：Mind Heist 换成 Challengers（更燥）；结尾的 hopeful piano 上一条讯飞片子也用过，介意的话换 `the_mountain-inspiring-technology`（从头就是满的，对齐点设 2 秒）或 `大气史诗-破晓曙光`。
  - 曲库里只有 7 个音效（whoosh、上扬、重击）。梦境段如果想要更「空灵」的声音（闪光、风铃类），需要另外找素材。

## 改东西去哪

| 想改 | 改哪里 | 之后跑 |
|---|---|---|
| 逐字稿 / 某句用哪段口播 | `代码/lines.py`、`代码/align.py`（`FIX` 手动修句子起止） | `python3 align.py && python3 build.py audio` |
| 句子之间的停顿 | `代码/build.py` 的 `PAUSE` | `python3 build.py audio` |
| 画面 | `网页版/s1.js`（1–5 句）`s2.js`（6–14）`s3.js`（16–27）`s4.js`（28–42）；公共函数在 `common.js` | 刷新网页 |
| 配乐 / 音效 | `代码/mix.py` | `python3 mix.py` |
| 背景图、梦境图 | `代码/assets.py` | `python3 assets.py` |

代码目录里的命令都在 `剪辑工程/代码/` 下跑。
